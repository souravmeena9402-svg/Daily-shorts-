# Thought Lab • Daily Shorts Studio
**Antigravity setup skill + a daily GitHub Actions job.** 720 × 1280 • 24 fps • original English voice + captions • no stock assets, music subscriptions or paid AI API.

## Start here
1. Unzip the entire folder, including `.agents` and `.github`. Play `Sample-Short.mp4` to hear the actual offline voice and see the default design. Open the project folder (the one containing `studio.json`) in Antigravity. Run `/daily-shorts`. If discovery is unavailable, paste: **“Read .agents/skills/daily-shorts/SKILL.md and README.md. Help me set up this studio, preview first, and do not publish until I approve.”**
2. Create a dedicated GitHub repo under your control; push **the contents** of the project to its default branch with git, not as a ZIP or a nested folder. Allow Actions and ensure the job's `GITHUB_TOKEN` can commit `state.json` to that branch (no PR-only protection there). Use trusted collaborators only; anyone who can edit workflow code can potentially access its secrets. In Actions → Daily Short → Run workflow → **preview**. Open the successful run → Artifacts → `shorts-preview`. No YouTube login required for preview.
3. In Google Cloud Console select/create a project, enable **YouTube Data API v3**, configure the OAuth consent screen (Google Auth Platform → Branding, Audience, Data Access), and for External/Testing add yourself as a test user. Create an **OAuth client → Desktop app** and download the client JSON **outside this repo**. The helper requests `youtube.upload` plus `youtube.readonly` to check your exact channel. Use an account that owns or manages the intended channel. This is user OAuth, not an API key or service account.
4. On your own computer install Python 3.10+ and GitHub CLI, sign in with `gh auth login`, then from the unzipped folder run (replace the example path/repo):
   ```sh
   python -m pip install -r requirements.txt
   python tools/connect.py "/path/outside/repo/client_secret.json" YOUR_GITHUB_NAME/YOUR_REPO
   ```
   Use `py` or `python3` if needed. Choose the right YouTube/Brand Account in the browser. Check the displayed channel name and ID against YouTube Studio, then type the ID to confirm. The helper sends the credential directly to Actions secret `YT_AUTH` and sets repository variable `CHANNEL_ID`; it doesn't print the token. Never paste credentials in Antigravity/chat or commit client JSON. If an External OAuth app is left in Testing, refresh tokens for these scopes generally expire after **7 days**. For continuing access configure an appropriate production consent status, complete verification if required and reconnect. This is separate from YouTube's upload audit.
5. Edit `studio.json`: decide if your videos are directed at children, then set `made_for_kids` to `true` or `false` (no quotes); `null` deliberately blocks uploads. Leave `privacy` at `private` initially. Commit/push. Manually run **upload** once and inspect the result in YouTube Studio. That upload consumes today's slot. Public scheduling won't retroactively change it.
6. After approval, choose `public`, `unlisted` or `private` in `studio.json`, commit/push, then set **Settings → Secrets and variables → Actions → Variables → New repository variable → `DAILY_ENABLED` = `true`**. Default target is daily **18:07 India time**, not an exact-time guarantee. The cron is UTC in `.github/workflows/daily.yml`. Use the default branch. PC and Antigravity may be closed. To pause: set `DAILY_ENABLED` to `false`. Manual uploads remain available.

## What actually changes each day?
`stories.py` contains seven authored, parameterized English lessons; `render.py` draws a model for each with Pillow, reads each beat using Flite's SLT voice, and encodes to MP4 with FFmpeg. No web scraping, stock image search or ongoing AI service. The first rotation covers echoes, swings, waves, falling objects, orbits, shadows and garden geometry. Further rotations change numerical examples, **not the underlying concept or story structure**. This is a repeatable teaching series, not unlimited new topics generated by AI. Review for variety and accuracy; repetitive uploads may not be suitable for monetization. Diagrams are schematic and not shown in real time.

To focus the channel, edit `topics` in `studio.json` (non-empty list of supported keys). Change `series` for the on-screen brand. To add genuinely new concepts, ask Antigravity: “Add three new English what-if concepts about light. Extend stories.py, TOPICS, render.py's animated scenes and studio.json; render one preview per concept. Keep assets free. Do not touch state or publish.” Review before pushing. Changing the topic list changes rotation from the current episode index; it does not reset the upload log.

## Costs and limits
There are no paid asset or voice services. Use a standard Linux runner. Private repo minutes, artifact storage, YouTube API quotas and account/channel upload restrictions apply; review GitHub Billing and set a spending limit that stops usage before overages. Usage may stop if allowance is exhausted. A scheduled job can be delayed or skipped; inactive public repos can have schedules disabled. Unverified YouTube API projects created after 28 July 2020 can be restricted to private uploads until the project passes YouTube's audit; selecting `public` in this kit cannot override it. See [YouTube videos.insert](https://developers.google.com/youtube/v3/docs/videos/insert), [OAuth token expiry](https://developers.google.com/identity/protocols/oauth2#expiration), and [GitHub scheduled events](https://docs.github.com/en/actions/reference/workflows-and-actions/events-that-trigger-workflows#schedule).

## Recovery / disconnect
- Actions → Daily Short → latest run contains the step error. Check credentials, quotas, branch write access, Actions allowance and API enablement. Re-run the desktop helper for expired/revoked tokens.
- A reserved `pending` item blocks further uploads, including after an ambiguous network failure. **Check Studio for the exact pending title and wait for processing before retrying.** If it exists, edit `state.json`: set `last_video` to its ID, `last_day` to the actual upload date in India (`YYYY-MM-DD`), `next` to pending episode + 1, and `pending` to `null`. If you confirm no video exists, clear only `pending`. Commit to default branch. Do not reset the whole file. There is no catch-up flood for missed days.
- To disconnect: pause schedule, delete `YT_AUTH` and `CHANNEL_ID`, then revoke the app in your Google Account's third-party access page.

## Optional local render (Ubuntu)
`sudo apt-get install ffmpeg flite fonts-dejavu-core`, install `requirements.txt`, then `python render.py 0`. Output: `output/short.mp4`. Preview and upload jobs install these tools automatically on GitHub. The included sample was rendered with this code. OAuth/upload must be verified with your own channel; no upload is made by opening this package.
